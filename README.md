# Mini-GFS Distributed Storage

Final project for Computer Architecture & Operating Systems.

## Topic 20: Mini-GFS

This project is a simplified distributed storage system inspired by Google File System.

## Team Contribution Plan

1. Ayau - Master Server
2. Aizada - Chunk Storage

4. Zhansaya - Client API
5. Karakat - DevOps 
6. Lyudmila - QA & Analytics

## Main Features

- Master server for metadata
- Chunkservers for file chunks
- Replication
- Client upload/download/list commands
- Docker Compose cluster
- Failure recovery demo
- AI usage report
- Optional frontend/dashboard visualization
